Multi-Agent AI Research & Decision Engine

Mar – Jun 2026
Problem
A single LLM call gives confident answers to complex business questions with no evidence and no check on whether they are right.
Solution
Five specialised agents research, retrieve, analyse, verify and decide, producing evidence-based recommendations with human approval before anything is final.
Tech stack
PythonLangGraphLangChainMCPFastAPIRAGPostgreSQLRedisPydantic
How it works
  1. Question in. A FastAPI endpoint receives the question and starts a LangGraph run with persistent workflow state.
  2. Research agent breaks the question into sub-questions and decides what evidence is needed.
  3. Retrieval agent runs RAG over the knowledge base and calls MCP tools for controlled access to external services and business systems.
  4. Data Analysis agent works through the retrieved data to produce figures and comparisons.
  5. Verification agent checks each claim against its sources; conditional routing sends weak findings back to retrieval, and failed steps retry.
  6. Decision agent writes the recommendation as structured output validated by Pydantic.
  7. Human approval before the decision is finalised and returned with its evidence.

AI-Powered Job Recommendation System

Jun – Aug 2025
Problem
Keyword matching misses good candidates whose profiles describe the same skills in different words, and gives no reason for a match.
Solution
Matches LinkedIn profiles to jobs by semantic similarity in a vector database, with five agents producing ranked, explainable recommendations.
Tech stack
PythonLLMsEmbeddingsVector searchRAGLinkedIn profile data
How it works
  1. Profile Analysis agent extracts skills, experience and projects from LinkedIn profile data.
  2. Job Requirement agent parses each posting into required skills, experience and preferences.
  3. Embed and index profiles and requirements in a vector database.
  4. Matching agent runs semantic similarity search instead of keyword overlap.
  5. Evaluation agent retrieves profile and job context with RAG and scores each fit.
  6. Recommendation agent returns a ranked list with a reason for every match.

Smart Retail Store Management & GenAI Assistant

Apr – Jun 2025
Problem
Store staff need fast answers about stock and sales, but letting an AI query the database risks exposing data a role should not see.
Solution
A role-based retail backend plus a RAG assistant that writes SQL from plain-English questions, gated by the caller's role permissions.
Tech stack
PythonFastAPIPostgreSQLSQLAlchemyRedisJWTRBACLangChainDockerGitHub Actions
How it works
  1. Sign in. The user gets a JWT carrying their role: Admin, Manager or Employee.
  2. Role-scoped API. Every route checks the role across employees, catalog, inventory, stock and sales.
  3. Data layer. SQLAlchemy models on PostgreSQL, with Redis for caching.
  4. Ask the assistant a plain-English question, such as which products are low on stock.
  5. RAG and SQL. LangChain retrieves schema and store context; the LLM writes the query.
  6. Permission gate. The query is checked against the caller's role before it runs.
  7. Ship. GitHub Actions runs tests and builds the Docker image.

Tech stack

How it works
  1. Agent calls a tool such as "read selection" or "create frame".
  2. MCP server in TypeScript on Bun turns the call into a command.

Healthcare Insurance Claim Prediction

Data & AI Day 2026 Hackathon
Problem
Predict claims from 476,000+ customer records where only 3.64% are positive, so a naive model just predicts "no claim".
Solution
Full modelling workflow with imbalance-aware features, cross-validation and an ensemble. Chennai Data Circle × Zerve AI.
Tech stack
PythonPandasscikit-learnXGBoostLightGBMCatBoostFeature engineering
Result
1.81× over baseline119,043 scored, 0 nulls
How it works
  1. EDA on 476,000+ records and 50 anonymised features: confirmed the 3.64% positive rate, dropped 5 near-constant features, found a high-risk segment with a 5.55% claim rate, and treated features with 69% missing data as signals.
  2. Missing-value indicators so the model learns from where data is absent.
  3. Target encoding for high-cardinality categorical features.
  4. Log transforms for heavily skewed numeric features.
  5. 5-fold stratified cross-validation on XGBoost, LightGBM and CatBoost, with scores consistent across every fold.
  6. Ensemble prediction on 119,043 unseen customers with zero nulls.
